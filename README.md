# 📚 Word Smart 1 — Interactive Vocabulary Lecture & Quiz Series

> Complete interactive HTML5 web app series for Princeton Review's **Word Smart 1** (Words 1 to 30), designed for BCS, Bank Officers, IBA, and university admission preparation in Bangladesh.

## 🚀 Key Features
- **100% Self-Contained:** Single-file HTML5/CSS3/JavaScript engine per episode (no build step or backend required).
- **Sequential Animation Flow:** Smooth word and meaning revelation (Word ➔ Synonyms ➔ Antonyms ➔ Example Sentence with Bengali Translation ➔ Mnemonic Memory Trick).
- **Interactive Revision Quizzes:** 3 BCS-standard MCQs per episode with a 5-second countdown timer and automatic answer explanation.
- **Quick Recap Slide:** 2-column master summary table prior to the quiz rounds.
- **Built-in High-Resolution Thumbnail Generator:** Direct export of 1080p, 2K, and 4K YouTube/social thumbnails (16:9, 9:16, 1:1, 4:5).
- **4K Video Exporter:** In-browser canvas recording with audio synthesis for YouTube video production.
- **Cross-Episode Navigation:** Unified top navigation bar across all episodes.

## 📖 Series Overview

### Part 1 (Words 1–10)
1. **Abash** (লজ্জিত বা অপ্রস্তুত করা)
2. **Abate** (হ্রাস পাওয়া বা কমানো)
3. **Abdicate** (ক্ষমতা বা সিংহাসন ত্যাগ করা)
4. **Aberration** (স্বাভাবিক নিয়মের বিচ্যুতি)
5. **Abhor** (তীব্র ঘৃণা করা)
6. **Abject** (চরম দুর্দশাগ্রস্ত / হীন)
7. **Abjure** (শপথপূর্বক পরিত্যাগ করা)
8. **Abnegate** (স্বার্থ ত্যাগ করা)
9. **Abominable** (ঘৃণ্য / জঘন্য)
10. **Abridge** (সংক্ষিপ্ত করা)

### Part 2 (Words 11–20)
11. **Abnegate** (স্বার্থ বা অধিকার ত্যাগ করা)
